# DevHouse

Landing page fictícia de compra e aluguel de imóveis, feita como projeto de estudo de Tailwind CSS.

🔗 **Demo:** https://matheusdiamantino.github.io/DevHouse-Tailwind/

## O que foi praticado

- HTML e **Tailwind CSS 3** (via CLI, com `tailwind.config.js`)
- Layout responsivo com grade de cards de imóveis
- JavaScript para abrir e fechar o menu mobile

## Como rodar

```bash
npm install
npm run dev        # gera styles/output.css em modo watch
npm run build:css  # gera o CSS minificado
```

Depois, sirva a pasta raiz com um servidor local (ex.: Live Server) e abra `src/index.html`.
